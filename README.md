# 矿物电子探针计算器

一个**单文件、离线可用**的矿物电子探针（EMP）数据计算程序。输入氧化物 wt%，自动给出：

- 以氧为基准的**晶体化学结构式**
- **Fe³⁺/Fe²⁺** 分配与估算依据
- **晶体化学位置**占位（T、M1、M2、A、B、C 等）
- 矿物**分类名称**与**端元组分**
- **批量计算**（从 Excel 复制粘贴 / CSV 导入 / CSV 导出）
- **三元/二维投图分类**（长石、辉石、橄榄石、石榴子石、尖晶石、磷灰石，以及角闪石、黑云母、白云母、绿泥石、电气石、绿帘石、钛铁矿；支持单样品与批量叠加、SVG/PNG 导出）

主程序只有一个文件：**`矿物电子探针计算器.html`**。双击即可在浏览器中打开，不需要安装 Python、Excel 插件或联网。

## 1. 快速开始

### 方式一：双击 HTML

双击 `矿物电子探针计算器.html`，用 Chrome、Edge、Firefox 等浏览器打开即可。

### 方式二：双击启动脚本

双击 `打开计算器.bat`，会用系统默认浏览器打开。

### 使用流程

1. 在左侧选择**矿物类型**（默认单斜辉石）。
2. 输入样品名和各氧化物 wt%（可先点“载入示例”）。
3. 点“计算结构式”，右侧立即显示结构式、参数和占位表。
4. 批量数据：切到“批量计算”，从 Excel 选中区域复制后粘贴，点“解析并计算”。
5. 投图：切到“投图分类”，选择“当前单样品”或“批量结果”，即可查看三元分类图并导出 SVG/PNG。

> 提示：按 `Ctrl + Enter` 可快速计算；输入框支持 `<0.01`、`b.d.`、`n.a.` 等写法，程序按 0 处理。

共 **18 种**矿物：

| 矿物 | 英文 | 氧基准 | 说明 |
|---|---|---:|---|
| 橄榄石 | Olivine | 4 O | Fo–Fa–Tp，默认全铁 Fe²⁺ |
| 斜方辉石 | Orthopyroxene | 6 O | En–Fs–Wo，化学计量法估算 Fe³⁺ |
| 单斜辉石 | Clinopyroxene | 6 O | En–Fs–Wo–Ac，化学计量法估算 Fe³⁺ |
| 角闪石 | Amphibole | 23 O | T/C/B/A 占位，简化 IMA 分类 |
| 黑云母 | Biotite | 24 O（含 OH） | T/八面体/层间，Mg# |
| 白云母 | Muscovite | 24 O（含 OH） | 白云母/钠云母/多硅白云母 |

| 石榴子石 | Garnet | 12 O | Prp–Alm–Sps–Grs–Adr–Uvr |
| 斜长石 | Plagioclase | 8 O | An–Ab–Or |
| 碱性长石 | Alkali feldspar | 8 O | Or–Ab–An |
| 尖晶石 | Spinel | 32 O | Sp–Hc–Mag–Usp–Chr 等 |
| 磁铁矿 | Magnetite | 32 O | Mag–Usp–Chr 等 |
| 钛铁矿 | Ilmenite | 6 O | Ilm–Hem–Gek–Pyr |
| 榍石 | Titanite | 5 O | Ca–Ti–Si 占位 |
| 绿帘石 | Epidote | 13 O（含 OH） | Ps（绿帘石分子） |

含结构水的矿物（角闪石、云母、绿泥石、电气石）不额外补入 H₂O，而是按矿物的**理想阳离子数 / 氧基准**归一化，结构 OH 已计入氧基准。这样可以避免因为 EMP 不测 H₂O 而系统性高估阳离子数。

## 3. Fe³⁺ 的处理方式

程序提供四种选项：

| 选项 | 行为 |
|---|---|
| **自动（推荐）** | 若输入了 Fe₂O₃，按 Fe₂O₃/FeO 分配；否则按矿物默认方法 |
| **电荷平衡** | 按氧基准和电荷平衡估算 Fe³⁺（固定阳离子数的矿物先缩放到目标阳离子数） |
| **全部按 Fe²⁺** | Fe³⁺ = 0，全铁计为 Fe²⁺ |
| **按输入 Fe₂O₃/FeO** | 只使用输入的 Fe₂O₃ 与 FeO 比例 |

各矿物的默认方法：

- **辉石、石榴子石、尖晶石、磁铁矿、钛铁矿**：由阳离子数与理想化学计量的偏差估算 Fe³⁺（与常用 EMP 表格的做法一致）。
- **绿帘石**：由八面体 Al 的不足估算 Fe³⁺（Ps 分子）。
- **角闪石、云母、绿泥石、电气石**：默认全铁按 Fe²⁺；如测了 Fe₂O₃，请选择“按输入 Fe₂O₃/FeO”。
- **橄榄石、长石、磷灰石、锆石**：默认全铁为 Fe²⁺。

> **重要**：EMP 全铁通常以 FeO 给出，Fe³⁺ 并不能由化学成分唯一确定。不同作者、不同温压计采用的 Fe³⁺ 估算方案不同，结果会有差异。发表前请用你所在实验室惯用的标准程序复核。

## 4. 批量计算

### 从 Excel 复制粘贴

在 Excel 中选中包含表头的区域（例如 `Sample, SiO2, TiO2, ...`），复制，粘贴到“批量数据”文本框，点“解析并计算”。

- 第一行必须是表头。
- 支持 Tab、逗号、分号分隔。
- 表头可写 `SiO2`、`SiO₂`、`SiO2(wt%)`、`二氧化硅` 等常见形式。
- 样品列可写 `Sample`、`样品`、`编号`、`No.`、`Comment` 等。
- 可选 `Mineral` / `矿物` 列；有该列时按行识别矿物，没有时统一使用左侧当前矿物。

### CSV 导入 / 导出

- “导入 CSV 文件”：读取 UTF-8 编码的 CSV。
- “载入批量示例”：填入 6 个不同矿物的示例数据，便于快速体验。
- “下载模板”：生成当前矿物的列模板。
- “导出结果 CSV”：导出全部结果，UTF-8 带 BOM，Excel 可直接打开。

> Excel 的 `.xlsx` 文件请先“另存为 CSV UTF-8”，或直接复制粘贴；程序不直接解析 `.xlsx`。

### 操作

1. 先计算单样品或批量数据。
2. 切到“投图分类”，选择“当前单样品”或“批量结果”。
3. 勾选/取消“显示样品名”；批量时不同样品自动用不同颜色。
4. 每张图右上角可导出 **SVG** 或 **PNG**；图下方“查看投图数据表”可复制端元数值。

### 口径说明

- 分类边界采用国际通用方案的**简化**版本：长石按 An=10/30/50/70/90、Or=10/35/65/90；辉石按简化 Morimoto 四边形；尖晶石按 50% 三端元；磷灰石按 50% 卤素/羟基端元。
- 石榴子石图不画边界，按最大端元命名；若 Pyralspite 或 Ugrandite 三端元合计 **<20%**，该图不投点，避免把富钙榴石误画到某个角落。
- 角闪石二维图仅适用于**钙质角闪石**；黑云母、绿泥石、电气石、绿帘石、钛铁矿的边界也为简化方案，正式发表请对照相应文献图版。

## 6. 计算口径与校验

### 归一化

1. 氧化物 wt% → 摩尔数（`wt / 分子量`）。
2. 按矿物氧基准求归一化系数。
3. 得到阳离子 apfu。
4. 按矿物规则分配 Fe³⁺/Fe²⁺。
5. 按晶体化学位置分配，生成结构式与参数。

### 与原始表格的校验

用你表格中的样品做了回归测试（`tests/engine.test.js`）：

| 参数 | 程序 | 原 Excel | 备注 |
|---|---:|---:|---|
| 橄榄石 Fo | 72.69% | 72.690% | 一致 |
| 橄榄石 Fa | 26.82% | 26.822% | 一致 |
| 斜长石 An | 64.95% | 64.953% | 一致 |
| 斜长石 Ab | 34.41% | 34.406% | 一致 |
| 单斜辉石 En | 43.30% | 43.298% | 一致 |
| 单斜辉石 Fs | 12.04% | 12.038% | 一致 |
| 单斜辉石 Wo | 43.17% | 43.172% | 一致 |
| 黑云母 Mg# | 0.652 | 0.652 | 一致 |
| 石榴子石 Adr | 15.96% | 16.22% | 端元分配略有差异 |
| 石榴子石 Grs | 82.65% | 82.40% | 端元分配略有差异 |

说明：

- 不依赖 Fe³⁺ 的参数（Fo、An、En/Fs/Wo、Mg# 等）与你的表格高度一致。
- 含 Fe³⁺ 的端元（如石榴子石 Adr/Grs、尖晶石端元）会因 Fe³⁺ 估算与端元混合模型不同而有小幅差异。
- 角闪石的“Mg#”在部分表格中指 **C 位 Mg#**；本程序同时输出全岩 `Mg#` 和 `Mg#(C)`。

## 8. 已知限制

1. **Fe³⁺ 不是唯一解**：没有 Fe₂O₃ 实测或氧逸度约束时，Fe³⁺ 只能按经验方案估算。
2. **角闪石分类是简化方案**：按 Leake et al. (1997) / IMA 2012 的主要判别参数简化命名；复杂成分（如含 Li、Zn、F 的角闪石）请结合完整分类图。
3. **尖晶石族端元是近似“定额”分配**：不同作者采用的端元混合模型（如理想端元、最小二乘、site assignment）会给出不同数值。
4. **电气石的 B₂O₃、Li₂O 常未测**：B 未测时按 3 apfu 处理，Li 未测时按 0 处理；这两项会显著影响电气石种属命名。
5. **绿泥石 28 O、云母 24 O、角闪石 23 O** 是常用惯例；不同实验室可能采用 22 O / 28 O 等不同基准，比较时请先统一基准。
6. **榍石、磷灰石、锆石** 的微量元素占位做了简化处理。
7. **分类图边界是简化方案**：三元图（长石、辉石、尖晶石、磷灰石）和二维图（角闪石、黑云母、白云母、绿泥石、电气石、绿帘石、钛铁矿）均按常用阈值近似；石榴子石低合计（<20%）不投点。正式发表请对照所用文献图版。
8. 程序输出用于科研参考，**不能替代**对分析质量、矿物共生关系和计算方案的判断。
